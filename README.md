# Můj Pokojíček

Hra pro děti (Godot 4.3, Android): vlastní panenka, pokojíček, kamarádi přes WiFi,
pexeso a minihra „Co se změnilo?“ za oknem.

## Aktualizace v aplikaci
- `updates/version.json` – čísla verzí (`content` = obsah, `apk` = nejnovější APK, `min_apk` = nejstarší APK, které obsah umí načíst)
- `updates/pokojicek.pck` – balíček obsahu; aplikace ho stáhne tlačítkem s mráčkem a načte při dalším spuštění
- APK patří do GitHub Releases jako `MujPokojicek.apk`

Návod k projektu je v `NAVOD.md`. Modely: KayKit (CC0), licence v `models/*/LICENSE.txt`.
